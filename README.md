# Сборник практических заданий (Windows Forms)

Данный проект представляет собой комплексное настольное приложение, разработанное на языке **C#** в **Microsoft Visual Studio (Windows Forms)**. Приложение объединяет в себе 8 различных мини-программ (заданий), доступ к которым осуществляется через единое интерактивное меню выбора.

##  Главное меню программы
При запуске приложения пользователя встречает форма **«Выбор задания»**, содержащая кнопки для быстрого перехода к любому из разработанных модулей.

---

##  Описание разработанных заданий

###  Задание 1. Игра «Угадай число»
* **Суть:** Программа загадывает случайное число от 1 до 100, а пользователь пытается его угадать.
* **Функционал:** Поле ввода числа, кнопка «Угадать!», счётчик количества попыток, динамическое текстовое поле «Подсказка» (больше/меньше) и кнопка «Заново» для перезапуска сессии.

### Задание 2. Генератор случайного цвета
* **Суть:** Демонстрация работы с палитрой цветов и динамическим изменением свойств элементов управления.
* **Функционал:** По нажатию на кнопку «Случайный цвет» фон формы окрашивается в произвольный цвет, генерируемый случайным образом.

###  Задание 3. Отображение текста (MessageBox)
* **Суть:** Отработка навыков получения данных из текстовых полей ввода и вызова диалоговых окон.
* **Функционал:** Пользователь вводит любой текст в текстовое поле, нажимает кнопку «Отобразить», после чего текст выводится на экран в виде всплывающего модального окна `MessageBox`.

###  Задание 4. Интерактивные кнопки
* **Суть:** Управление видимостью или свойствами элементов интерфейса при взаимодействии.
* **Функционал:** Форма содержит текстовую строку ввода и три кнопки. При нажатии на кнопку её название или связанное действие переносится в строку состояния / текстовое поле.

###  Задание 5. Динамические подсказки
* **Суть:** Работа с событиями нажатия и изменением текста меток (Label).
* **Функционал:** На форме расположены 4 кнопки. При нажатии на любую из них рядом мгновенно отображается соответствующий текст (например, *"текст виден при нажатии на кнопку X"*).

###  Задание 6. Блокировка интерфейса
* **Суть:** Управление доступностью элементов управления (свойство `Enabled`).
* **Функционал:** Текстовое поле ввода можно заблокировать от редактирования с помощью кнопки «Блокировать» и вернуть в исходное состояние кнопкой «Разблокировать».

###  Задание 7. Текстовые Заметки
* **Суть:** Работа с многострочным текстовым полем (`RichTextBox` / `TextBox` Multiline) и файловой системой.
* **Функционал:** Полноценное мини-приложение для ведения записей. Кнопка «Сохранить» записывает введённый текст в файл, а кнопка «Загрузить» считывает сохранённый текст обратно в форму.

###  Задание 8. Калькулятор (Два варианта реализации)
Проект содержит два абсолютно разных интерфейсных подхода к созданию калькулятора:
1. **Вариант 1 (Классический):** Имеет отдельные текстовые поля для `числа 1`, `операции`, `числа 2` и `ответа`. Выбор операции (+, -, *, /) происходит по нажатию на соответствующие маленькие кнопки, а расчёт производится кнопкой «Рассчитать!».
2. **Вариант 2 (Инженерный/Плиточный):** Имитирует реальный калькулятор. Содержит общее табло вывода и полноценную сетку кнопок с цифрами (0-9), математическими знаками, точкой для дробей, а также кнопками «Стереть» и «=».
